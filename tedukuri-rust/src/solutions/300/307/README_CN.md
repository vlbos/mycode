307\. 连通图





 




  

求N个节点的无向连通图有多少个，节点有标号，编号为 1∼N1∼N。

例如下列图示，三个节点的无向连通图共4个。

!* 1737_1.jpg 


#### 输入格式

输入包含多组测试数据。

每组数据包含一个整数N。

当输入为0时，表示输入终止。

#### 输出格式

每组测试数据输出一个结果，每个结果占一行。

#### 数据范围

1≤N≤50

#### 输入样例：

    1
    2
    3
    4
    0
    

#### 输出样例：

    1
    1
    4
    38
