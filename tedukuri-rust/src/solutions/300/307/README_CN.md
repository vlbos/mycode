307\. 连通图

*    [题目](https://www.acwing.com/problem/content/description/309/)
*    [讨论](https://www.acwing.com/problem/content/discussion/index/309/1/)
*    [题解](https://www.acwing.com/problem/content/solution/309/1/)
*    [视频讲解](https://www.acwing.com/problem/content/video/309/)

  

求 NN 个节点的无向连通图有多少个，节点有标号，编号为 1∼N1∼N。

例如下列图示，三个节点的无向连通图共 44 个。

![1737_1.jpg](https://cdn.acwing.com/media/article/image/2019/02/17/19_3da24c4c32-1737_1.jpg)

#### 输入格式

输入包含多组测试数据。

每组数据包含一个整数 NN。

当输入为 00 时，表示输入终止。

#### 输出格式

每组测试数据输出一个结果，每个结果占一行。

#### 数据范围

1≤N≤501≤N≤50

#### 输入样例：

    1
    2
    3
    4
    0
    

#### 输出样例：

    1
    1
    4
    38
    

难度：困难

时/空限制：1s / 64MB

总通过数：618

总尝试数：1484
