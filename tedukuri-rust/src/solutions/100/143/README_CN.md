143	最大异或对
在给定的 N 个整数 A<sub>1</sub>，A<sub>2</sub>……A<sub>N</sub> 中选出两个进行 xor（异或）运算，得到的结果最大是多少？

输入格式
第一行输入一个整数 N。

第二行输入 N 个整数 A<sub>1</sub>～AN。

输出格式<br>
输出一个整数表示答案。

数据范围<br>
1≤N≤10<sup>5</sup>,<br>
0≤A<sub>i</sub><2<sup>31</sup>

**输入样例：**

    3
    1 2 3 

**输出样例：**

    3
