130\. 火车进出栈问题

*    [题目](https://www.acwing.com/problem/content/description/132/)
*    [讨论](https://www.acwing.com/problem/content/discussion/index/132/1/)
*    [题解](https://www.acwing.com/problem/content/solution/132/1/)
*    [视频讲解](https://www.acwing.com/problem/content/video/132/)

  

一列火车 nn 节车厢，依次编号为 1,2,3,…,n1,2,3,…,n。

每节车厢有两种运动方式，进栈与出栈，问 nn 节车厢出栈的可能排列方式有多少种。

#### 输入格式

输入一个整数 nn，代表火车的车厢数。

#### 输出格式

输出一个整数 ss 表示 nn 节车厢出栈的可能排列方式数量。

#### 数据范围

1≤n≤600001≤n≤60000

#### 输入样例：

    3
    

#### 输出样例：

    5
    

难度：中等

时/空限制：1s / 64MB

总通过数：3296

总尝试数：11846
