213\. 古代猪文

给定整数 n,qn,q，计算 q∑d|nCdnmod999911659q∑d|nCndmod999911659。

#### 输入格式

输入包括一行，包含两个整数 n，qn，q，用一个空格隔开。

#### 输出格式

输出包括一行，包含一个整数表示最终结果。

#### 数据范围

1≤n,q≤1091≤n,q≤109

#### 输入样例：

    4 2
    

#### 输出样例：

    2048
    

**提示**:对于 nn 的每一个正因数 dd，都有一个 CdnCnd 的值，将它们全部加起来得到的和就是 ∑d|nCdn∑d|nCnd。

难度：困难

时/空限制：1s / 64MB

总尝试数：2403
