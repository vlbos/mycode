278\. 数字组合

*    [题目](https://www.acwing.com/problem/content/description/280/)
*    [讨论](https://www.acwing.com/problem/content/discussion/index/280/1/)
*    [题解](https://www.acwing.com/problem/content/solution/280/1/)
*    [视频讲解](https://www.acwing.com/problem/content/video/280/)

  

给定 NN 个正整数 A1,A2,…,ANA1,A2,…,AN，从中选出若干个数，使它们的和为 MM，求有多少种选择方案。

#### 输入格式

第一行包含两个整数 NN 和 MM。

第二行包含 NN 个整数，表示 A1,A2,…,ANA1,A2,…,AN。

#### 输出格式

包含一个整数，表示可选方案数。

#### 数据范围

1≤N≤1001≤N≤100,  
1≤M≤100001≤M≤10000,  
1≤Ai≤10001≤Ai≤1000,  
答案保证在 int 范围内。

#### 输入样例：

    4 4
    1 1 2 2
    

#### 输出样例：

    3
    

难度：简单

时/空限制：1s / 64MB
