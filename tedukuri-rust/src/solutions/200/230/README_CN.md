230\. 排列计数





 




  

求有多少种长度为n的序列A，满足以下条件：

1.  1∼n1∼n 这n个数在序列中各出现了一次。
2.  若第i个数 A\[i\]A\[i\] 的值为i，则称i是稳定的，序列恰好有m个数是稳定的。

由于满足条件的序列可能很多，所以请你将序列数对 109+7109+7 取模后输出。

#### 输入格式

第一行一个数T，表示有T组数据。

接下来T行，每行两个整数 n、mn、m。

#### 输出格式

输出T行，每行一个整数，表示求出的序列数对 109+7109+7 取模后的值。

#### 数据范围

T≤500000,n≤1000000,m≤1000000T≤500000,n≤1000000,m≤1000000

#### 输入样例：

    5
    1 0
    1 1
    5 2
    100 50
    10000 5000
    

#### 输出样例：

    0
    1
    20
    578028887
    60695423
