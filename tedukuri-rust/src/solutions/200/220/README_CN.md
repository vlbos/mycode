给定整数 NN，求 1≤x,y≤N1≤x,y≤N 且 GCD(x,y)GCD(x,y) 为素数的数对 (x,y)(x,y) 有多少对。

GCD(x,y)GCD(x,y) 即求 x，yx，y 的最大公约数。

输入一个整数 NN。

#### 输出格式

输出一个整数，表示满足条件的数对数量。

#### 数据范围

1≤N≤1071≤N≤107

#### 输出样例：
