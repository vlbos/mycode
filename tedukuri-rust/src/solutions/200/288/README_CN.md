288\. 休息时间





 




  

在某个星球上，一天由N个小时构成，我们称0点到1点为第1个小时、11 点到2点为第2个小时，以此类推。

在第i个小时睡觉能够恢复Ui点体力。

在这个星球上住着一头牛，它每天要休息B个小时。

它休息的这B个小时不一定连续，可以分成若干段，但是在每段的第一个小时，它需要从清醒逐渐入睡，不能恢复体力，从下一个小时开始才能睡着。

为了身体健康，这头牛希望遵循生物钟，每天采用相同的睡觉计划。

另外，因为时间是连续的，即每一天的第N个小时和下一天的第1个小时是相连的（NN 点等于0点），这头牛只需要在每N个小时内休息够B个小时就可以了。

请你帮忙给这头牛安排一个睡觉计划，使它每天恢复的体力最多。

#### 输入格式

第1行输入两个空格隔开的整数N和B。

第 2..N+12..N+1 行，第 i+1i+1 行包含一个整数Ui。

#### 输出格式

输出一个整数，表示恢复的体力值。

#### 数据范围

3≤N≤3830  
2≤B<N2≤B<N  
0≤Ui≤200000

#### 输入样例：

    5 3
    2
    0
    3
    1
    4
    

#### 输出样例：

    6
    

#### 样例解释

这头牛每天3点入睡，睡到次日1点，即 \[1,4,2\]\[1,4,2\] 时间段休息，每天恢复体力值最大，为 0+4+2\=60+4+2\=6。
