203\. 同余方程

*    [题目](https://www.acwing.com/problem/content/description/205/)
*    [讨论](https://www.acwing.com/problem/content/discussion/index/205/1/)
*    [题解](https://www.acwing.com/problem/content/solution/205/1/)
*    [视频讲解](https://www.acwing.com/problem/content/video/205/)

  

求关于 xx 的同余方程 ax≡1(modb)ax≡1(modb) 的最小正整数解。

#### 输入格式

输入只有一行，包含两个正整数 a,ba,b，用一个空格隔开。

#### 输出格式

输出只有一行，包含一个正整数 xx，表示最小正整数解。

输入数据保证一定有解。

#### 数据范围

2≤a,b≤2×1092≤a,b≤2×109

#### 输入样例：

    3 10
    

#### 输出样例：

    7
    

难度：简单

时/空限制：1s / 64MB

总通过数：7051

总尝试数：10088
