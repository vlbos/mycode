225\. 矩阵幂求和





 




  

给定 n×nn×n 矩阵A和正整数k，求和 S\=A+A2+A3+…+AkS\=A+A2+A3+…+Ak。

#### 输入格式

输入只包含一个测试用例。

第一行输入包含三个正整数 n，kn，k 和m。

接下来n行，每行包含n个非负整数（均不超过 32,76832,768），用以描绘矩阵A。

##### 输出格式

按与描述矩阵A相同的方式，输出将S中所有元素对m取模后得到的矩阵。

#### 数据范围

1≤n≤30,  
1≤k≤109,  
1≤m<1041≤m<104

#### 输入样例:

    2 2 4
    0 1
    1 1
    

#### 输出样例：

    1 2
    2 3
