205\. 斐波那契





 




  

在斐波那契数列中，Fib0\=0,Fib1\=1,Fibn\=Fibn−1+Fibn−2(n\>1)Fib0\=0,Fib1\=1,Fibn\=Fibn−1+Fibn−2(n\>1)。

给定整数n，求Fibnmod10000。

#### 输入格式

输入包含不超过100组测试用例。

每个测试用例占一行，包含一个整数n。

当输入用例 n\=−1n\=−1 时，表示输入终止，且该用例无需处理。

#### 输出格式

每个测试用例输出一个整数表示结果。

每个结果占一行。

#### 数据范围

0≤n≤2×1090≤n≤2×109

#### 输入样例：

    0
    9
   99999
    1000000000
    -1
    

#### 输出样例：

    0
    34
    626
    6875
