245\. 你能回答这些问题吗





 




  

给定长度为N的数列A，以及M条指令，每条指令可能是以下两种之一：

1.  `1 x y`，查询区间 \[x,y\]\[x,y\] 中的最大连续子段和，即 maxx≤l≤r≤ymaxx≤l≤r≤y{∑i\=lrA\[i\]∑i\=lrA\[i\]}。
2.  `2 x y`，把 A\[x\]A\[x\] 改成y。

对于每个查询指令，输出一个整数表示答案。

#### 输入格式

第一行两个整数 N,MN,M。

第二行N个整数 A\[i\]A\[i\]。

接下来M行每行3个整数 k,x,yk,x,y，k\=1k\=1 表示查询（此时如果 x\>yx\>y，请交换 x,yx,y），k\=2k\=2 表示修改。

#### 输出格式

对于每个查询指令输出一个整数表示答案。

每个答案占一行。

#### 数据范围

N≤500000,M≤100000N≤500000,M≤100000,  
−1000≤A\[i\]≤1000−1000≤A\[i\]≤1000

#### 输入样例：

    5 3
    1 2 -3 4 5
    1 2 3
    2 2 -1
    1 3 2
    

#### 输出样例：

    2
    -1
