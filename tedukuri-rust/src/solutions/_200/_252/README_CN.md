252\. 树





 




  

给定一个有N个点（编号 0,1,…,N−10,1,…,N−1）的树，每条边都有一个权值（不超过1000）。

树上两个节点x与y之间的路径长度就是路径上各条边的权值之和。

求长度不超过K的路径有多少条。

#### 输入格式

输入包含多组测试用例。

每组测试用例的第一行包含两个整数N和K。

接下来 N−1N−1 行，每行包含三个整数 u,v,lu,v,l，表示节点u与v之间存在一条边，且边的权值为l。

当输入用例 N\=0，K\=0N\=0，K\=0 时，表示输入终止，且该用例无需处理。

#### 输出格式

每个测试用例输出一个结果。

每个结果占一行。

#### 数据范围

1≤N≤104,  
1≤K≤5×1061≤K≤5×106,  
0≤l≤103

#### 输入样例：

    5 4
    0 1 3
    0 2 1
    0 3 2
    2 4 1
    0 0
    

#### 输出样例：

    8
