89\. a^b

*    [题目](https://www.acwing.com/problem/content/description/91/)
*    [讨论](https://www.acwing.com/problem/content/discussion/index/91/1/)
*    [题解](https://www.acwing.com/problem/content/solution/91/1/)
*    [视频讲解](https://www.acwing.com/problem/content/video/91/)

  

求 aa 的 bb 次方对 pp 取模的值。

#### 输入格式

三个整数 a,b,pa,b,p ,在同一行用空格隔开。

#### 输出格式

输出一个整数，表示`a^b mod p`的值。

#### 数据范围

0≤a,b≤1090≤a,b≤109  
1≤p≤1091≤p≤109

#### 输入样例：

    3 2 7
    

#### 输出样例：

    2
    

难度：简单

时/空限制：1s / 32MB
